A queue, explained to a 10-year-old in two lines: one vivid sentence built on a single analogy, and one honest sentence about what that analogy maps and what it leaves out.

## The entry

> A queue is a slow caterpillar made of people, each person a segment shuffling forward one tiny step at a time until the front reaches the door.
>
> The caterpillar shows how the whole line creeps forward together and why cutting in would snap it, but it leaves out that people choose to join and can walk away any time, while a caterpillar's segments never can.

## Run it

```sh
python3 main.py
```

This writes the two lines to `/output/entry.txt` (358 characters, UTF-8). The program is fully deterministic — no network, no randomness, no wall clock — so every run produces the same bytes. `main.py` also self-checks the house gate before writing: 1–400 characters, not only white space, exactly two lines.
